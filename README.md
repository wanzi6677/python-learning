## 几个值得一提的练习

### 第四章：成都历史天气爬虫（`06`）

- 分页抓取 24 个月的历史天气数据
- 处理表格末尾的"翻页行"（该行没有日期，需过滤）
- 3 次重试 + 请求间隔限流
- 按日期去重并排序，产出约 50KB CSV

### 第四章：TMDB 电影榜单（`05` / `07` / `08`）

- 抓取 + 正则清洗（`1h 19m` → `79m`、年份去括号、上映时间去国家后缀）
- pandas 统计四个维度（年份/语言/类型/评分）
- Altair 可视化 + Streamlit 看板

### test：金融数据管道练习

- 脏数据清洗（重复行、空值、`N/A`、三种日期格式混用、负数）
- 金融指标计算（总收益率、日波动率、最大回撤）
- **数据源适配层**：发现东方财富接口不可用后切换到新浪源，并加了一层适配来统一列名格式
